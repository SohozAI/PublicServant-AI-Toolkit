# PublicServant-AI-Toolkit
A curated collection of AI prompts, tutorials, and automation workflows designed specifically for public sector office tasks
* **AI-Powered Task Breakdown:** Inspired by [goblin.tools](https://goblin.tools), this feature automatically deconstructs complex or overwhelming tasks into actionable, step-by-step sub-tasks.
* **AI-Generated Study Aids:** Inspired by [thea.study](https://thea.study), this feature automatically converts static documents and notes into interactive flashcards, quizzes, and learning tools.
* **AI-Powered Deep Research:** Inspired by Stanford's [STORM](https://storm.genie.stanford.edu/), this feature autonomously searches the web to generate comprehensive, Wikipedia-style articles on any given topic.
* **Automated Literature Reviews:** Inspired by [Elicit](https://elicit.com/), this feature uses AI to quickly search, summarize, and synthesize findings across a massive database of academic papers. It automatically pulls key metrics, methodologies, and specific concepts directly from dense research PDFs, bypassing hours of manual screening. It transforms the tedious process of analyzing academic literature into an efficient, structured, and highly accessible overview of the evidence.
